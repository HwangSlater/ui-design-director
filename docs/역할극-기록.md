# 역할극 기록 — 스킬을 고친 근거

스킬을 고칠 때마다 새 세션을 디자이너로, 메인 세션을 의뢰인(사장님)으로 두고 시안을 끝까지 만들어 본다. 의뢰인이 짚기 전에 디자이너가 먼저 했는지, 같은 틀로 나오지 않았는지, 토큰이 어디서 드는지를 본다.

## 하는 법

0. 역할극 자료(시안·사진)는 `C:\Users\doorc\Downloads\ui-design-director-역할극\` 아래 시안\·사진\ 에 모은다. 진행 중인 것만 Downloads 바로 아래에 두고 끝나면 옮긴다.
1. 사장님 사진: 한 가게를 한 사람이 같은 날 찍은, 상업 이용 되는 사진(위키미디어 공용 CC0 등)을 `C:\Users\doorc\Downloads\ui-design-director-역할극\사진\사장님-사진-<업종>\` 에 받고 `출처.md` 에 사진마다 사람·남의 간판·전화번호·값표를 적는다.
2. 사장님 역할 메모(메뉴·값·쉬는 날·채널·싫은 것·사진 속 누구 것)를 먼저 써 두고, 묻는 것에만 같은 말로 답한다.
3. 새 세션에 `/ui-design-director <가게> 홈페이지. 의뢰인은 사장님(메인 세션, 역할극 — 답은 SendMessage). 프로젝트 폴더: … 사장님 사진: …` 를 붙인다.
4. 디자이너 메시지를 받을 때마다 구간 줄을 `docs/roleplay-phases/<이름>.txt` 에 더하고, 끝나면 `python -X utf8 scripts/roleplay_tokens.py <세션 ID> <구간 파일>` 로 센다.
5. 아니다 싶으면(같은 틀, 토큰이 지난번을 따라감) 중간에 멈추고 원인부터 고친다.

## 배운 것

- **같은 틀은 규칙이 만든다.** 카페와 분식집 1차가 참고가 달랐는데도 같은 부품(테두리 가게 이름·이름–값 줄·남색 단추 하나+글자 링크·날짜 알림 줄)으로 나왔다. AI 티를 피하려고 넣은 「이렇게 하라」 규칙이 정답 틀이 됐다. 규칙은 금지만 두고, 부품 모양은 이번 참고(n/N곳)와 가게 물건에서 고르게 바꾼 뒤(`DESIGN.md` § 부품 출처) 2차는 벽 차림판을 세로 글씨 그대로 옮긴 메뉴, 이번 주 칠 일 달력, 「제33호」 번호판이 나왔다.
- **공통점만으로는 평균 웹사이트가 나온다.** 깡통구제도 카페·분식집과 같은 모양(흰 바탕·가는 선·각진 칸·강조색 하나)이 됐다. `skeleton.mjs` 가 재는 숫자(한 단 비율, 모서리 0px, 각진 단추, 위 메뉴·끝 전화)는 어느 사이트 묶음이든 같고, 「한 곳에만 있는 것은 옮기지 않는다」가 각 사이트의 생김새를 지워 빈자리를 모델 기본값이 채웠다. 견본 틀은 「참고만」으로 표에서 빠졌다. 사용자 정정: 고른 템플릿(바탕)의 디자인·레이아웃을 비슷하게 따르고, 관련 사이트 여럿의 공통점이 있는 곳만 다르게 → `skeleton.mjs --base`(`skeleton_base.mjs`), `DESIGN.md` § 바탕에서 바꾼 곳, preflight 「바탕 빠짐」. 지금 시안에 돌리니 「바탕의 짜임을 버림: 바탕 33%, 우리 100%」로 걸렸다.
