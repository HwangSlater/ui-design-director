# 역할극 기록 — 스킬을 고친 근거

스킬을 고칠 때마다 새 세션을 디자이너로, 메인 세션을 의뢰인(사장님)으로 두고 시안을 끝까지 만들어 본다. 의뢰인이 짚기 전에 디자이너가 먼저 했는지, 같은 틀로 나오지 않았는지, 토큰이 어디서 드는지를 본다.

`<역할극 폴더>` 는 역할극 자료를 모으는 내 컴퓨터의 폴더(저장소 밖)다. 아래에 시안\·사진\·비교\ 를 둔다.

## 하는 법

0. 역할극 자료(시안·사진)는 `<역할극 폴더>\시안\`·`<역할극 폴더>\사진\` 에 모은다. 진행 중인 것만 그 위 폴더에 두고 끝나면 옮긴다.
1. 사장님 사진: 한 가게를 한 사람이 같은 날 찍은, 상업 이용 되는 사진(위키미디어 공용 CC0 등)을 `<역할극 폴더>\사진\사장님-사진-<업종>\` 에 받고 `출처.md` 에 사진마다 사람·남의 간판·전화번호·값표를 적는다.
2. 사장님 역할 메모(메뉴·값·쉬는 날·채널·싫은 것·사진 속 누구 것)를 먼저 써 두고, 묻는 것에만 같은 말로 답한다.
3. 새 세션에 `/ui-design-director <가게> 홈페이지. 의뢰인은 사장님(메인 세션, 역할극 — 답은 SendMessage). 프로젝트 폴더: … 사장님 사진: …` 를 붙인다.
4. 디자이너 메시지를 받을 때마다 구간 줄을 `docs/roleplay-phases/<이름>.txt` 에 더하고, 끝나면 `python -X utf8 scripts/roleplay_tokens.py <세션 ID> <구간 파일>` 로 센다.
7. **통과 기준(2026-11-10 사용자)**: session_audit 빠진 일·어긴 일 0, 넘길 때 preflight 걸림 0, 세 쪽 비교에서 「오답지 쪽」 1개 이하·「우리만 다름」 0(두 폭 모두). 통과하면 다른 주제로 넘어가 같은 순서(스킬 세션·오답지·세 쪽)를 되풀이하고, **4번 연속 통과**하면 끝. 못 넘으면 스킬을 고쳐 같은 주제를 다시.
6. 같은 메모로 스킬 없는 세션(`claude --disallowedTools Skill`, 플러그인 없이)도 돌려 오답지를 만들고, `node scripts/triad.mjs <결과.md> base=<바탕 주소> ours=<우리 시안> ai=<오답지>` 로 세 쪽을 견준다. 「오답지 쪽」「우리만 다름」 항목은 스킬(규칙·점검·도구)을 고쳐 다음 세션이 처음부터 피하게 한다 — 시안은 손대지 않는다.
5. 도중과 끝에 `python -X utf8 scripts/session_audit.py <프로젝트 폴더> --memo <의뢰인 메모>` 로 디자이너가 단계마다 정해진 도구를 제때·순서대로 썼는지, 하면 안 되는 일(사본 손으로 지우기·보기 화면 손으로 쓰기·마지막 고침 뒤 점검 빼먹기)을 했는지, 메모의 값이 시안에 들어갔는지 본다. 기대하는 일은 그 파일의 STEPS 한 곳에만 적는다.
5. 아니다 싶으면(같은 틀, 토큰이 지난번을 따라감) 중간에 멈추고 원인부터 고친다.

## 반복 시험(2026-11-06부터, 사용자 지시)

디자인이 좋아질 때까지 주제와 의뢰인 역할을 바꿔 가며 역할극을 되풀이하고, 매번 스킬·규칙을 고친다.
- 의뢰인은 **메인 페이지만** 요청한다(SKILL § Main page recipe). 다 만들지 않는다.
- 목표: 참고 사이트의 디자인을 따르되 베낀 티가 나지 않게. 스킬 없이 만든 것보다 나아야 한다.
- 메인 페이지 index 가 어느 정도 나오면 멈추고 사용자에게 경로를 알려 판별을 받는다. 판별 전에는 「됐다」고 하지 않는다.
- 토큰: 회차마다 `roleplay_tokens.py` 로 재고, 메인 페이지까지 80번 안쪽을 목표로 한다.
- 회차마다 이 문서 표에 한 줄, 고친 것은 「배운 것」에 한 줄.
